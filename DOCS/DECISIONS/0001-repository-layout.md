# ADR 0001 — 리포지토리 구조

- 상태: 채택
- 일자: 2026-08-18

## 맥락

50주 자율주행 SW 학습 로드맵(아티팩트 `AD Software Plan`)을 실제 코드로 진행한다.
로드맵은 교재 15권의 이론 학습과 단일 ROS2 스택의 점진적 구현이라는 두 축으로 되어 있다.
이 둘을 어디에 둘 것인가를 정해야 했다.

## 결정

### 1. 리포지토리를 둘로 나눈다

| 리포 | 담는 것 | 공개 |
|---|---|---|
| `ihmmaru99/ADS` | 최종 AD 소프트웨어. colcon 워크스페이스 | PUBLIC |
| `ihmmaru99/SELF_STUDY` | 교재 예제 타이핑 · 드릴 · 실험 | PRIVATE |

경계 기준은 **"이 코드가 최종 스택에 남는가"** 다.
`ad_core` 에 들어갈 클래스는 ADS, 문법 연습은 SELF_STUDY.

교재 본문은 ADS 에 옮기지 않는다. ADS 가 공개 리포이기 때문이다.

### 2. ADS 루트 자체를 colcon 워크스페이스로 둔다

`ADS/src/` 아래에 패키지가 바로 들어간다. `cd ADS && colcon build` 가 바로 된다.
대안이던 `ADS/ad_stack_ws/src/` 는 빌드할 때 한 단계 더 들어가야 해서 버렸다.
`build/` `install/` `log/` 가 리포 루트에 생기므로 `.gitignore` 로 막는다.

### 3. 폴더 대문자 규칙의 예외

관리 폴더(`DOCS` · `TOOLS`)는 대문자를 쓴다.
`src/` 아래 ROS2 패키지는 **소문자 snake_case** 를 쓴다 — ament 요구사항이라 협상 대상이 아니다.

### 4. `src/` 를 빈 골격으로 시작한다

각 패키지에 유효한 `package.xml` 과 `CMakeLists.txt` 만 두고 구현은 비운다.
라이브러리 · 실행 타깃 블록은 CMakeLists 에 주석으로 남겨 두고 해당 주차에 활성화한다.

**감수하는 비용**: 아티팩트의 2주차 목표 "차가 움직이는 것을 본다"를 그대로는 못 맞춘다.
`ad_core` 와 `ad_sim_bicycle` 을 직접 구현해야 폐루프가 돌므로 첫 주행은 Phase 2(8~14주) 부근이 된다.

**얻는 것**: 완성된 스타터킷을 읽고 넘어가는 대신 직접 짜면서 막힌다.
정답 코드는 학습 허브 아티팩트에 참조 파일 49개로 남아 있어 언제든 열어볼 수 있다.

### 5. IHMJB 최상위는 git 저장소로 만들지 않는다

`ADS` · `SELF_STUDY` · `LeetCode` 가 각각 독립 리포이고 `CARLA_SIM` 은 12GB 바이너리다.
상위를 리포로 묶으면 서브모듈 관리 비용만 생기고 얻는 것이 없다.

## 결과

- 두 리포를 독립적으로 공개 범위 · 커밋 리듬을 정할 수 있다
- ADS 의 커밋 히스토리가 그대로 설계 판단 기록이자 포트폴리오가 된다
- 새 폴더(예: 별도 실험 프로젝트)를 IHMJB 아래에 자유롭게 추가해도 서로 간섭하지 않는다
